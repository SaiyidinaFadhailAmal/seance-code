# Product Vision: SéanceCode (Kiroween 2026 — Costume Contest)

## Core Concept
SéanceCode is a Victorian Apothecary & Occult Archival Ledger web application where developers perform a "Digital Séance" to diagnose haunted stack traces, cursed legacy code, and critical bugs, banishing them into clean, production-ready code.

## Aesthetic & UX Principles (Bespoke Editorial Design)
- **Visual Theme:** Warm Abyssal Obsidian (`#0B0A09`), Tarnished Antique Brass (`#C59B52`), Aged Parchment Ivory (`#EAE2D3`), Crimson Wax (`#C84648`), and Verdigris Copper (`#4E9A74`) with subtle SVG film-grain texture and architectural corner registration marks.
- **Typography:** Editorial display serif (`Cormorant Garamond`), engraved small-caps (`Cinzel`), and monospaced code (`JetBrains Mono`).
- **Interactive Rituals:** Features an animated calibrated brass astrolabe during diagnosis, sequential fault trace cards, side-by-side cursed vs. purified code comparison, keyboard shortcuts (`Ctrl+Enter`), and a Roman-numeral indexed Grimoire ledger.
