# SéanceCode — The AI Bug & Legacy Code Exorcist

Built solo for **Kiroween 2026 (Costume Contest Category)**.

SéanceCode transforms debugging and legacy code refactoring into an interactive Victorian Gothic séance ritual. Paste broken code or stack traces into the Summoning Altar to uncover root causes, trace astral fault nodes, generate purified code, and archive banished bugs in a persistent SQLite Grimoire.

## Built With Kiro

- **Spec-Driven Development (`.kiro/specs/`):** Structured EARS requirements, technical architecture design, and incremental tasks before writing application code.
- **Steering Docs (`.kiro/steering/`):** Enforced bespoke Obsidian & Tarnished Brass UI palette (`#0B0A09`, `#C59B52`, `#EAE2D3`), XSS-safe rendering, and resilient API fallbacks.
- **Agent Hooks (`.kiro/hooks/`):** Automated `pytest` and `hypothesis` property-based verification whenever backend files are edited.
